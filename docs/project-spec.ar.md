## 1. نظرة عامة

### 1.1 عن Deniz
Deniz متجر لبيع شموع معطّرة بأشكال لطيفة. كل شمعة إلها لمسة خاصة، ومصنوعة يدوياً بحب واهتمام، لتكون جزء من المناسبة وهدية بتبقى ذكرى.

كل القطع **بتنعمل عالطلب ومخصّصة**. الزبونة بتشوف الأعمال السابقة كأمثلة، وبتطلب متلها بالألوان والاسم أو العبارة والكمية اللي بدها ياها.

**الأقسام:**
- **توزيعات المناسبات:** مواليد (بيبي)، وتخرّج، وخطوبة أو زواج.
- **هدايا شمع لكل المناسبات:** متل بوكسات الورد الشمعي، أو شمعة بشكل حسب الطلب.

**مكان العمل:** دمشق، مع شحن لكل المحافظات.

### 1.2 المشكلة
الشغل حالياً كله عن طريق إنستغرام، وهاد بيسبب المشاكل التالية:
- **المواعيد:** بتضيع مواعيد التسليم.
- **التفاصيل:** تفاصيل الطلبات (الألوان، والأسماء، والكميات) بتضيع بين الرسائل.
- **استفسارات الزبائن:** الزبائن بيضلّوا يسألوا "شو صار بطلبي؟".
- **المواد الخام:** ممكن تخلص مادة بلا ما ننتبه.
- **الأسعار:** ممكن ينعطى سعر غلط، أو تنتسى الأسعار.
- **الحسابات:** ما في طريقة لمعرفة الربح أو الخسارة كل شهر.

### 1.3 الأهداف

**أهداف العمل:**
- تنظيم الطلبات والمواعيد والحسابات بمكان واحد.
- إظهار صورة احترافية ومنظّمة لـ Deniz قدام الزبائن.
- معرفة الكلفة والربح الحقيقيين لكل طلب ولكل شهر.

**أهداف المشروع:**
- إثبات القدرة على بناء نظام متكامل بمعايير الشركات: تحليل متطلبات، وتصميم، واختبارات، وتوثيق، ونشر حقيقي.

### 1.4 ربط المشاكل بالميزات

| المشكلة | الميزة اللي بتحلّها |
|---|---|
| ضياع مواعيد التسليم | تقويم الطلبات (FR-22، FR-23) |
| ضياع التفاصيل بالرسائل | فورم الطلب أونلاين (FR-05، FR-06) |
| أسئلة الزبائن عن طلباتهن | صفحة تتبّع الطلب (FR-11، FR-12) |
| خلوص المواد بلا انتباه | المواد الخام مع تنبيه (FR-28) |
| أسعار غلط أو منسية | سعر ثابت بالكتالوج، وحساب تلقائي للمجموع (FR-03، BR-5) |
| عدم معرفة الربح | المصاريف والتقارير الشهرية (FR-31، FR-32) |

## 3. النطاق

**داخل النطاق:**
- موقع عام للزبائن بالعربي والإنجليزي.
- لوحة تحكم لإدارة الطلبات، والكتالوج، والمواد، والتسعير، والحسابات.
- توليد عروض أسعار وفواتير PDF.

**خارج النطاق (حالياً):**
- الدفع الإلكتروني بالبطاقة جوّا الموقع.
- حسابات للزبائن (اسم مستخدم وكلمة سر).
- ربط مباشر مع نظام شركة القدموس.
- تطبيق موبايل. الموقع بيشتغل عالموبايل من المتصفح.

## 4. المتطلبات الوظيفية

### 4.1 الموقع العام

**الكتالوج**
- **FR-01** عرض الأعمال بقسمين: **توزيعات** مرتّبة حسب المناسبة (مواليد، وتخرّج، وخطوبة أو زواج)، و**هدايا** لكل المناسبات.
- **FR-02** لكل قطعة: صور، ووصف، والخيارات المتاحة (ألوان، وحجم، واسم أو عبارة).
- **FR-03** لكل قطعة **سعر ثابت** للقطعة الواحدة. بعض القطع إلها **أحجام**، وكل حجم إله سعر (مثلاً: بوكسات الورد إلها 3 أحجام).
- **FR-04** زر **"بدي متل هاد"** بيفتح فورم الطلب والقطعة مختارة فيه.

**فورم الطلب**
- **FR-05** الزبونة بتعبّي: المناسبة، وتاريخ المناسبة، والقطع المطلوبة (لكل قطعة: العدد، والألوان، والاسم أو العبارة)، وملاحظات.
- **FR-06** الطلب الواحد ممكن يحتوي **أكتر من نوع قطعة**.
- **FR-07** رفع صورة مرجعية (اختياري).
- **FR-08** اختيار طريقة الاستلام:
  - **توصيل جوّا دمشق:** الزبونة بتختار منطقتها، وأجرة التوصيل بتنضاف للمجموع تلقائياً.
  - **شحن للمحافظات عن طريق القدموس:** بيطلع للزبونة تنبيه إنو أجرة الشحن بتدفعها للشركة عند الاستلام، وإنو لازم تحوّل المبلغ كامل قبل الشحن.
- **FR-09** حماية الفورم من السبام.
- **FR-10** بعد الإرسال، الطلب بيوصل للوحة التحكم بحالة **"جديد"**.

**تتبّع الطلب**
- **FR-11** كل طلب إله كود أو رابط خاص، صعب يتخمّن.
- **FR-12** صفحة التتبّع بتعرض: حالة الطلب، وتاريخ التسليم، والمجموع، والمدفوع، والباقي.
- **FR-13** لما تتغيّر حالة الطلب بلوحة التحكم، صفحة التتبّع بتتحدّث تلقائياً.

**اللغة**
- **FR-14** الموقع كامل بالعربي (من اليمين لليسار) وبالإنجليزي، مع زر تبديل.

### 4.2 لوحة التحكم

**إدارة الطلبات**
- **FR-15** عرض كل تفاصيل الطلب: الزبونة، والمناسبة، والتاريخ، والقطع، والألوان، والنص، والصورة المرجعية، والأسعار.
- **FR-16** مراحل الطلب: جديد ← مؤكد ← قيد التحضير ← جاهز ← تم التسليم.
- **FR-17** تحذير عند تغيير الحالة إذا الدفعة المطلوبة ما انسجّلت (BR-7).

**الدفع**
- **FR-18** لكل طلب بتنختار طريقة الدفع: **حوالة** أو **عند الاستلام**.
- **FR-19** **الحوالة:** تسجيل المبلغ ورقم الحوالة، مع إمكانية رفع صورة الإشعار.
- **FR-20** **عند الاستلام:** المبلغ بيضل بحالة "مع شب التوصيل" لحتى المديرة تأكّد إنها استلمته.
- **FR-21** لكل طلب بينعرض: المجموع، والعربون، والمدفوع، والباقي.

**التقويم**
- **FR-22** عرض كل الطلبات حسب تاريخ المناسبة.
- **FR-23** إبراز الطلبات اللي لازم تخلص هالأسبوع، واللي موعدها قرّب.

**عروض الأسعار والفواتير**
- **FR-24** عرض سعر PDF قبل التأكيد، وفاتورة PDF بعد التأكيد، بلوغو Deniz.
- **FR-25** فيهن: التفاصيل، والمجموع، والعربون، والمبلغ الباقي.

**التسعير وحساب التكلفة**
- **FR-26** "وصفة" لكل نوع قطعة: شو المواد الخام اللي بتدخل فيها، وقديش من كل وحدة.
- **FR-27** حساب الكلفة الحقيقية والربح، وسعر مقترح للطلبات الكبيرة.

**المواد الخام**
- **FR-28** إدارة المواد (شمع، وألوان، وفتايل، وعلب، وشرائط، وورد مجفف، وكروت، وستيكرات) مع الكميات.
- **FR-29** تنبيه لما تقرّب أي مادة تخلص.

**الزبائن**
- **FR-30** معلومات التواصل، وحساب إنستغرام، وكل الطلبات السابقة لكل زبونة.

**المصاريف والتقارير**
- **FR-31** تسجيل المصاريف حسب النوع: مواد، وتغليف، وتوصيل، وإعلانات.
- **FR-32** تقارير شهرية: عدد الطلبات، والأرباح، وأكتر مناسبة بتجيب شغل، وأكتر قطع مطلوبة.

**إدارة الكتالوج**
- **FR-33** إضافة القطع وتعديلها وإخفاؤها، مع الصور.

**مناطق التوصيل**
- **FR-34** إدارة قائمة مناطق دمشق وأجرة كل منطقة، من مكان واحد.

**الحسابات والصلاحيات**
- **FR-35** تسجيل دخول للمديرة والمساعدة، بالصلاحيات المذكورة بالقسم 2.

## 5. قواعد العمل

| # | القاعدة |
|---|---|
| **BR-1** | **توصيل جوّا دمشق:** أجرة ثابتة حسب المنطقة، وبتنضاف لمجموع الطلب تلقائياً. |
| **BR-2** | **شحن للمحافظات:** عن طريق شركة القدموس. الأجرة بتحددها الشركة، والزبونة بتدفعها للشركة مباشرة عند الاستلام، وهي **مش** جزء من مجموع الطلب. |
| **BR-3** | **الدفع عند الاستلام:** لطلبات دمشق بس. |
| **BR-4** | **طلبات المحافظات:** لازم تندفع **كاملة بالحوالة** قبل الشحن. |
| **BR-5** | **لقطة السعر:** سعر القطعة بينحفظ مع الطلب لحظة إنشائه. أي تغيير لاحق بسعر الكتالوج ما بيأثر على الطلبات القديمة ولا فواتيرها. |
| **BR-6** | **العربون حسب نوع الطلب:** طلبات **توزيعات المناسبات** ما بتتثبّت إلا بعد دفع عربون بالحوالة. طلبات **الهدايا** (متل بوكس ورد شمع، أو شمعة وحدة) ما بتحتاج عربون. نوع القطعة (توزيعات أو هدية) **ثابت** عليها بالكتالوج. |
| **BR-7** | **قواعد الدفع مرنة:** إذا العربون أو الحوالة المطلوبة ما انسجّلت، النظام بيطلّع **تحذير** بس عند تغيير الحالة، والقرار للمديرة. النظام **ما بيمنع**. |
| **BR-8** | **المساعدة** ما بتشوف أي معلومة عن التكاليف أو الأرباح أو التقارير. |
